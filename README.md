> A curated list of tools, APIs, platforms, automation frameworks, integrations, business solutions, learning resources, and communities for WhatsApp.

WhatsApp is one of the world's most widely used messaging platforms, serving billions of users across personal communication, customer support, commerce, marketing, notifications, and business operations. Its ecosystem includes APIs, automation tools, chatbots, integrations, analytics platforms, and enterprise communication solutions.

This list is intended for developers, businesses, marketers, customer support teams, automation engineers, entrepreneurs, and anyone building solutions around WhatsApp.

## APIs & Developer Tools

Developer tools and APIs for integrating WhatsApp into applications.

- [WhatsApp Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api/) — Official cloud-hosted WhatsApp API.
- [Twilio Messaging API](https://www.twilio.com/docs/whatsapp) — Messaging API supporting WhatsApp.
- [Baileys](https://github.com/WhiskeySockets/Baileys) — TypeScript and JavaScript WhatsApp Web API library.
- [whatsapp-web.js](https://github.com/pedroslopez/whatsapp-web.js) — Node.js client library for WhatsApp Web.
- [OpenWA](https://github.com/open-wa/wa-automate-nodejs) — WhatsApp automation framework for Node.js.
- [Venom Bot](https://github.com/orkestral/venom) — WhatsApp automation framework.
- [WhatsUsernames.link API](https://whatsusernames.link/developers) — Free, keyless REST API for WhatsApp username/phone links, QR codes, and Business Platform BSUID tools.
